# Chocolatey package for twodb-node

The nuspec (`twodb-node.nuspec`) carries the package metadata; CI stamps the release tag over its `__VERSION__` placeholder before running `choco pack`. The scripts in `tools/` do the work: `chocolateyinstall.ps1` copies the agent exe and WinSW into `%ProgramFiles%\TwodbNode`, writes `twodb-node-service.xml` (the WinSW service config, picking up `TWODB_NODE_URL`/`TWODB_NODE_TOKEN`/`TWODB_ROOT` from machine environment variables), registers the service, and adds a `twodb-node` shim on `PATH` via `Install-BinFile` (Chocolatey only auto-shims exes inside the package dir, not ProgramFiles); `chocolateyuninstall.ps1` stops and removes the service, the install dir, and the shim. In CI, the freshly built `twodb-node-windows-x64.exe` and a downloaded `WinSW.exe` are copied into `tools/` just before packing, so only the nuspec and scripts live in git.
